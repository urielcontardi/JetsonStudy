Referência da API

Todas as rotas abaixo são públicas pelo prefixo /api. Os botões executam chamadas contra o próprio device usando a origem atual.

Base URL
Não use as portas internas dos containers.
GET/healthz Confirma que a Clip API está respondendo. 

            


            

              

                GET/cameras
                Lista IDs de câmera encontrados no índice de segmentos.
                
              

              

            


            

              

                GET/range
                Retorna primeiro e último timestamp gravado para a câmera.
                
              

              

                

                
                

              

            


            

              

                GET/segments
                Lista os segmentos que intersectam um intervalo UTC.
                
              

              

                
Use timestamps ISO 8601, por exemplo 2026-06-09T12:00:00Z.

                

                  

                  

                  

                

                
                

              

            


            

              

                GET/clips
                Gera um MP4 standalone a partir do intervalo gravado.
                
              

              

                

                  

                  

                  

                

                
                

              

            


            

              

                GET/events
                Consulta eventos locais por câmera e intervalo.
                
              

              

                

                  

                  

                  

                

                
                

              

            


            

              

                GET/events/{event_id}/clip
                Baixa o MP4 finalizado associado a um evento.
                
              

              

                

                
                

              

            


            

              

                GET/orwell/events/{sensor_id}
                Contrato consumido pelo Friday para listar vídeos do sensor.
                
              

              

                

                  

                  

                  

                

                
                

              

            


            

              

                GET/orwell/clip/{sensor_id}/{event_id}
                Entrega ao Friday o MP4 standalone de um evento.
                
              

              

                

                  

                  

                

                
                

              

            


            

              

                GET/config
                Lê a configuração de upload periódico exposta ao portal.

                Atualiza estado e intervalo do upload periódico.
                
              

              

                
Body JSON: {"periodic_upload_enabled": true, "periodic_upload_interval_s": 300}. Use o formulário de Upload periódico acima para alterar com validação.

              

            


            

              

                GET/upload-stats
                Retorna pendências, falhas e timestamp do último upload.

Uma borda HTTP

            
O navegador acessa apenas /, /api e /preview. Nginx no Compose e Traefik no K3s preservam o mesmo contrato.

          

          

            
Mídia finalizada

            
O recorder publica clip.mp4 atomicamente. Clip API e uploader nunca consomem fragments ainda abertos.

          

          

            
Pronto para K3s

            
Apps HTTP usam targetPort 8080; Services apresentam porta 80 ao Traefik. RTSP e WebRTC continuam protocolos dedicados.

Como acessar

          
A URL não muda conforme a rede. Apenas o hostname ou IP que resolve o device muda.

        

        

          

            
LAN e Tailscale

            

              

              

              

              

            

          

          

            

              Regra operacional: não acesse diretamente 8080 ou
              8888. Essas portas pertencem à rede interna dos serviços.
              Use sempre a origem pública do gateway.
